# 模块 D：讲解视频（Manim 管线）

**定位**：概念有动态过程、培训/课堂场景、视觉通道收益 > 文字成本时启用。
**不适用**：时效性内容（视频生产周期 > 文本，过时即废）；无动态过程的纯陈述。

## 铁律：脚本先行（Script-First）

**先写旁白脚本，再写代码。** 没有口播稿的 Manim 生成 = 动画自嗨。
旁白稿结构（60-90 秒）：钩子（≤5s，反直觉事实/问题）→ 一句话版本 → 展开 2-3 段 → 结论 + 行动指向。
写完脚本先给用户确认，再生成画面。

## 生成流程

1. 运行环境检查：`python3 scripts/env_check.py`
   - 全部通过 → 继续
   - 缺依赖 → 走**降级路线**（见文末），不要在缺环境时硬写代码
2. 写旁白脚本（`.md`），确认后转 TTS：`edge-tts --voice zh-CN-XiaoxiaoNeural --file script.md --write-media narration.mp3`（`edge-tts --list-voices` 查看全部中文声线）
3. 按脚本设计场景列表：每个段落 = 1 个 Scene；视觉必须服务脚本句子（脚本每句话都有画面任务，画面不许"自顾自炫技"）
4. 用 `assets/manim_scene_template.py` 写场景代码，渲染：
   ```bash
   manim -pqh script.py SceneName   # -qh 高质量1080p；-qm 中质量预览；-ql 快速草稿
   ```
5. 合成：`ffmpeg -i narration.mp3 -i scene.mp4 -c:v copy -c:a aac -shortest final.mp4`
6. 交付：mp4 路径 + 脚本副本 + 场景 .py 源文件

## 视觉规范（3B1B 风格要点）

- 一个场景一个核心视觉隐喻，全场贯穿（如"水流=电流"）
- 元素入场必须有理由（引导注意力），禁无目的动画
- 文字 ≤ 12 字/屏；公式只在必要时出现，出现后必须停留 ≥ 3 秒
- 配色固定 4-5 色（蓝=核心对象，橙=对比/变化，灰=背景，黄=高亮，红=警示）
- 节奏：每 3-5 秒必须有视觉变化

## 验收清单

- [ ] 先有脚本后有代码（交付物里必须能找到脚本文件）
- [ ] 脚本 60-90 秒（超了先砍内容，不加速画面）
- [ ] 每句话都有对应画面任务，且画面在执行该任务
- [ ] 一个核心视觉隐喻贯穿全片
- [ ] 无 LaTeX 编译依赖（用 `Text` 而非 `Tex`，除非环境确认有 latex）
- [ ] 渲染后实际播放检查：节奏、错别字、音画同步

## 降级路线（本机环境不满足时）

按优先级：
1. **导出可移植渲染包**：输出 `script.py` + `render.sh`（内含安装命令）+ `script.md` 旁白稿，用户在本地/Colab 一条命令渲染
2. **降机制**：退回模块 C（HTML 讲解页），视频钩子改为嵌入静态图解
3. **纯脚本交付**：旁白稿 + 分镜表（场景 | 画面 | 时长），交给视频同事制作

## 常见问题

- **中文渲染方块字**：Manim 的 `Text` 默认字体不含中文，必须显式指定：`Text("示例文本", font="Noto Sans CJK SC")`。本 skill 模板已内置中文字体处理函数。
- **edge-tts 不可用**：网络受限时退化为字幕轨（ffmpeg 烧录 subtitles），或仅交付无声视频+脚本。
- **渲染慢**：先用 `-ql` 快速迭代，定稿再 `-qh`。
