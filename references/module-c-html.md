# 模块 C：单文件 HTML 讲解工件

**定位**：有审美/交互要求的讲解载体。领导简报、产品讲解页、培训教程、调研成果展示。
**不适用**：需要打印/存档的正式文档（用 A）、纯内部草稿。

## 四级递进（源自 Thariq Shihipar 框架，社区实现参考 robonuggets/html-it）

| 级别 | 形态 | 典型场景 | 投入 |
|---|---|---|---|
| 1 Static Doc | HTML ≈ 更好看的 Markdown |  specs、报告、讲解稿 | 低 |
| 2 Visual Artifact | + SVG 图解、排版、表格 | 方案讲解、概念可视化 | 中 |
| 3 Two-Way Interactive | + 滑块/开关/输入，实时反馈 | 参数敏感性演示、方案对比 | 高 |
| 4 Throwaway Tool | 专用小工具（拖看板、配置器） | 演示优于讲述（见模块 E） | 按需 |

**升级规则：默认从 1 开始，只有当受众需要"操作一下才懂"时才升 3/4。** 多数讲解停在 2 是最佳状态。

## 设计规范（防 AI slop，写进每一个生成工件）

- **字体**：正文系统字体栈（中文 PingFang/Microsoft YaHei，英文 Georgia/serif + system-ui）；禁用 Inter/Roboto 默认脸
- **配色**：一个主色 + 中性灰阶；禁蓝紫渐变；对比度 ≥ 4.5:1；浅色底深字
- **布局**：内容最大宽度 720-860px 居中；章节间留白 > 装饰线
- **零外部依赖**：所有 CSS/JS 内联；不得引用 CDN 字体/库（单文件可分享是核心约束）
- **结构**：标题(结论式) → 一句话版本(高亮块) → 主体分段 → 图解区 → 附录(来源/术语表)
- **交互件**（级别 3+）：每个控件旁标注"你在调什么、调的后果是什么"

## 生成流程

1. 受众四问 + 定级别
2. 复制模板：`cp assets/explain-page.html <输出名>.html`，在模板的 `<!-- SECTIONS -->` 区填内容
3. 如涉及图解：嵌入模块 B 产出的 SVG 或 Mermaid（内联 mermaid.js 仅限 3.6KB 极简版时可用；默认渲染成静态 SVG 内嵌，保证单文件零依赖）
4. 自检清单逐项过
5. 交付文件路径 + 截图（可用浏览器工具渲染验证）

## 验收清单

- [ ] 单文件、零外部依赖（`grep -E "https?://" 输出文件` 只允许出现在正文链接，不允许在 link/script/img 标签的 src）
- [ ] 标题是结论句
- [ ] 首屏有一句话版本（30 秒内）
- [ ] 无蓝紫渐变、无 Inter 默认字体、无卡片无意义堆砌
- [ ] 手机宽度（375px）下可读
- [ ] 每个术语首次出现就地解释
- [ ] 级别 3+ 的控件有语义标注；有"导回文本"按钮（Copy as markdown / 导出结论）
