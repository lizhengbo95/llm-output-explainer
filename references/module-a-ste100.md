# 模块 A：受控语言（STE100）

**定位**：跨语言、跨时间、高歧义成本的文本。给 AI agent 读的指令、操作手册、技术文档、API 文档、需要存档的规范。
**不适用**：说服、营销、演讲稿、情感表达。受控语言消除歧义，但不负责好听。

## 核心规则（简化版 STE100）

### 句子层
- 句子 ≤ 25 个词
- 一个句子只表达一个指令/事实
- 优先：主动语态 > 被动语态
- 技术指令用祈使句（"Connect the cable." 而非 "The cable should be connected."）

### 词汇层
- 一词一义：全文同一概念用同一词（建立术语表，见下）
- 不用比喻、习语、双关（"hit the ground running" → "start work immediately"）
- 不用含糊修饰（"as soon as possible" → "within 24 hours"）
- 能具体就具体（"several" → 具体数字；"large" → 具体尺寸/阈值）

### 结构层
- 操作步骤 → 编号列表；并列项 → 项目符号
- 警告/注意：置于步骤之前，用 `WARNING:` / `NOTE:` 前缀
- 条件必须显式："If X, do Y. If not X, do Z."（禁止让受众推断 else 分支）

### 术语表（受控文本 >200 词时必附）
表格：`术语 | 定义（≤20字） | 禁用替换词`。全文术语必须与术语表逐字一致。

## 快速自检（可配合 scripts/ste100_check.py）

- [ ] 全文最长句 ≤ 25 词
- [ ] 无被动语态技术指令（find -ing/should be/was done）
- [ ] 无隐喻/习语（检查引号、比喻动词）
- [ ] 所有数字、阈值、条件显式写出
- [ ] 警告在步骤之前
- [ ] 术语全文一致（脚本可扫）

## 中文场景的对应规则

STE100 为英文设计。中文受控写作对应规则：
- 句长 ≤ 60 字（中文信息密度高）
- 不用" thereof /  thereof 类"翻译腔；不用四字成语堆砌
- "的地得"规范、量词规范（"一个数据" → "一条数据"）
- 数字优先用阿拉伯数字 + 单位（"三分钟左右" → "约 3 分钟"）
- 同术语表规则
